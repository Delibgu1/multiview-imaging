CRS — Sistema de Coordenadas

Em uma frase: o CRS é o “idioma do mapa”: define como cada ponto é colocado na Terra. No Brasil, o padrão oficial é SIRGAS 2000. Para trabalhar e medir em metros, use a versão UTM da zona do seu projeto.

Quando usar cada um?

  • SIRGAS 2000 / UTM (recomendado para medição): projetos oficiais (CAR, SIGEF, licenciamento, perícia), cartografia/engenharia, relatórios onde área/ distância precisam estar corretas em metros. É o sistema padrão do Brasil.
  • WGS84 / UTM (recomendado para navegação/compatibilidade): integração com GPS, monitores de máquinas, KML/GPX, aplicativos móveis e telemetria — é o sistema mais comum nesses equipamentos. Também trabalha em metros (por ser UTM), então medições continuam coerentes.
  • WGS84 (graus) EPSG:4326: ótimo para visualização global e web, mas não use para calcular áreas/ distâncias (está em graus). Prefira sempre uma versão UTM (em metros) quando for medir.

Como escolher a zona UTM

Use a zona onde seu projeto está (hemisfério Sul). O Brasil vai, grosso modo, de 18S a 25S. O mapa abaixo ajuda a localizar a zona.

Dica prática: combine com o cliente qual CRS será entregue. Para fluxo interno/medições, SIRGAS 2000/UTM é excelente; para navegação/maquinário, muitos pedem WGS84/UTM. Ambos funcionam — use o que atende a necessidade, e mantenha consistência.
