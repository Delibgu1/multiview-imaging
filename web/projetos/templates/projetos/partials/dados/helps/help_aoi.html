AOI — Área de Interesse

O que é: a AOI define o polígono que representa a área do seu projeto. Com base nela o sistema calcula a área (ha), cruza com a área declarada e orienta as próximas etapas.

Métodos de entrada
  1. Upload de polígono (GeoJSON)
    • Arquivos aceitos: .geojson ou .json.
    • Geometrias aceitas: Polygon ou MultiPolygon.

    Exemplo mínimo (Polygon):

    {
  "type": "Polygon",
  "coordinates": [[
    [-55.8502, -12.3301],
    [-55.8420, -12.3400],
    [-55.8305, -12.3312],
    [-55.8502, -12.3301]
  ]]
}

    Observação: GeoJSON usa [longitude, latitude] (graus decimais) e o primeiro/ último vértice devem ser iguais para fechar o polígono.

  2. Digitar coordenadas dos vértices
    • Formato: graus decimais no CRS padrão do projeto: WGS84 (EPSG:4326).
    • Campos: Lat (ex.: -12.330100) e Lon (ex.: -55.850200).
    • Informe ao menos 3 vértices; o sistema fecha o polígono automaticamente repetindo o primeiro ponto.
  3. Sem AOI agora
    • Você pode salvar o projeto sem AOI e preencher depois.
Resultados e usos
  • Área calculada (ha): derivada da AOI (somente leitura).
  • Comparação: área declarada × calculada com Δ (diferença).
  • Finalidade = oficial: após informar a AOI será possível visualizar um croqui (mapa) com os segmentos a, b, c, ... e registrar confrontantes (nome/documento) para memorial descritivo.

Dica: se você trabalha em outro sistema de referência, converta para WGS84 (EPSG:4326) antes do upload. O cálculo de área é feito em projeção de área equivalente internamente.
